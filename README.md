# Rae's Study Note

An offline Indonesian study app built around UGM INCULS's *Titian Bahasa Pemula 1*.
One self-contained HTML file: tap any Indonesian word or sentence to hear it,
plus a searchable glossary, a spaced-review mode and situational drills.
Interface in Chinese, Japanese and English.

**Just open it: https://belajar.rae.work** — it runs straight in a mobile
browser; add it to your home screen and it behaves like an app, no install
needed.

> A personal study tool, shared with classmates. Fork it and swap in your own
> material; see below.

---

## Getting started

Requires [Node.js](https://nodejs.org/) 20+. Generating speech also needs
`ffmpeg` and an [ElevenLabs](https://elevenlabs.io/) API key (skip it if you
don't need synthesized audio — the app falls back to the device's built-in
speech).

```bash
npm install
npm run validate     # checks content: structure, trilingual completeness, register values, duplicate vocab, render smoke test, drill pool, audio coverage
npm run build        # → dist/rae-study-notes.html (single file, works offline)
npm run preview      # starts a local server; open it from your phone on the same Wi-Fi
```

Other commands:

| Command | What it does |
| --- | --- |
| `npm run tts` | Incrementally synthesizes speech (only what's missing; reports the count and estimated cost first) |
| `npm run site` | Builds the hostable `docs/` (HTML + audio + `CNAME` + `.nojekyll`, with analytics injected) |
| `npm run prepare-assets` | Copies the build output into the Android `assets/` folder (also run by the cloud packaging step) |
| `npm run apk` | Builds the Android APK (via GitHub Actions) |

## Layout

| Directory | What it is |
| --- | --- |
| `content/` | **The single source of content**: lessons, vocab, drills, UI copy, config |
| `src/` | Template `template.html`, styles `app.css`, engine `engine.js` |
| `scripts/` | Validate / build / speech / preview / packaging pipeline |
| `audio/` | Speech library (files named by a hash of their read-aloud text; an append-only cache) |
| `dist/` | Build output, not committed |
| `docs/` | Website build output, generated by `npm run site`. **This one IS committed** (Pages publishes from it), but don't hand-edit it |
| `.github/` | Workflow that builds the APK in the cloud |
| `android-app/` | Native WebView shell that packages the same HTML into an APK |
| `.claude/skills/` | Skills for Claude Code: turning classroom material into a lesson, and packaging the app |

Everything in `content/` is JSON. Learner-facing text is always a
`{"zh":…, "ja":…, "en":…}` trilingual object; Indonesian text is always a
plain string. Run `npm run validate` after any change — its nine checks will
flag anything wrong.

## Using your own material

1. Replace the lessons in `content/lessons/` with your own, swap
   `content/vocab.json` for your own vocabulary, and `content/drills.json`
   for your own drill bank.
2. In `content/meta.json`, change the app name, what units are called
   (Bab / Pelajaran / Unit), which languages are required
   (`required_langs`), and which ElevenLabs voice to use.
3. Also in `content/meta.json`: `app.id` (determines the output filename),
   `app.repo` (the footer link), and `learner` (the nationality placeholders
   used in example sentences) — and **clear out `site.analytics_token`**,
   or your traffic data will land on the original author's dashboard.
4. `npm run validate` → `npm run build`.

To publish to your own domain: `npm run site -- --domain your.domain` →
commit `docs/` → repo Settings → Pages, select `main` / `/docs`; point your
DNS at `<username>.github.io` with a CNAME record. **If your DNS is on
Cloudflare, that record must be grey-clouded (DNS only)** — proxying
(orange cloud) breaks certificate issuance.

The content format is documented in
[`.claude/skills/lesson/references/lesson-spec.md`](.claude/skills/lesson/references/lesson-spec.md).
If you also use Claude Code, `.claude/skills/lesson/` in this repo is a
ready-made skill: drop a photo of a textbook page or a handout into
`inbox/`, and it turns it into a complete lesson (trilingual glosses,
register tagging, vocabulary intake, drills, speech synthesis).
